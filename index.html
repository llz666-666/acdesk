Windows / macOS 桌面端

AC台

AI Agent 协作系统桌面端，下载解压即可使用。

Windows 下载20 MB · 便携版 macOS 下载27 MB · Apple Silicon

Windows 解压后双击「启动AC台.vbs」；macOS 解压后把 ACDesk.app 移到桌面。

三步开始使用

01 选择系统下载

Windows 选择左侧蓝色按钮，macOS 选择黑色按钮。

02 解压压缩包

解压后保留 ACDesk.app 或「启动AC台.vbs」所在文件夹。

03 双击打开

macOS 首次打开若被拦截，右键 ACDesk.app 再选择「打开」。
